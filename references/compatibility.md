# 米家 / 小爱 / 付费视频：家庭电视兼容性红线

本页适用于 **任何去广告、换 Launcher、精简、清理、升级**。优先保留正在使用的功能，
而不是追求删除更多系统包。运行只读检查：
`bash scripts/tv-preflight.sh <TV_IP>`。

## 不得按包名猜测“冗余”

**默认禁止**卸载、禁用、清数据、替换或重置以下能力相关 App/服务：

- 米家与米家连接服务、MiOT/设备联动、小米账号、设备认证。
- 小爱同学/语音控制、系统 UI、投屏/发现服务、HDMI 输入源管理、电视基础设置。
- 付费视频（银河奇异果/爱奇艺、腾讯视频、优酷等）及其登录、授权、DRM、牌照/播放服务。
- 上海电信 IPTV 机顶盒/运营商网络业务；不得修改机顶盒认证及光猫 IPTV 业务。

**包名因固件/版本变化而不同**：只读脚本打印可疑相关包供人工核对，
不能靠正则表达式给出卸载许可。特别注意：`com.mitv.tvhome`、`com.android.tv.settings`
的改动会影响桌面与兜底页，必须在**确认机型、已有备用入口与可回滚能力**后单独操作。

## 为什么换桌面一般不会取消会员？

Launcher 管理的是“首页入口”，不是视频服务商的订阅权益。
只替换桌面而**保留 App 数据和认证环境**，通常能继续在原 App 登录播放，
但不能保证每个 MIUI TV 固件的内容跳转/系统服务依赖完全一致，因此必须回归测试。

注意：爱奇艺 **黄金/基础会员**不等于电视端银河奇异果会员权益。
已购买白金/星钻或单独电视端会员的用户，应在原 App 内核实权益，
不能通过第三方播放器“继承”或绕过权益。

## 变更前后对照检查（先截图/记录，后验证）

| 功能 | 变更前确认 | 变更后验收 |
| --- | --- | --- |
| 米家 | 手机米家可看见电视；电视米家可控制家居 | 手机/电视双向控制仍有效；确认同一小米账号及米家授权 |
| 小爱 | 语音控制电视、授权设备 | 语音唤醒、控制、投屏等可继续使用 |
| 爱奇艺/奇异果 | 原 App 的账号、会员标识、收藏/播放记录、付费片播放 | 原 App 可启动、显示原权益、播放受保护视频且声音正常 |
| 其他付费 App | 账号、会员和具体影片正常 | 相同账号及影片继续正常播放 |
| IPTV | 实际 HDMI 端口、直播、回看、声音 | 相同 IPTV 订阅依然有效，能切回 HOME |
| 小米系统 | 设置、输入源、遥控器 HOME、投屏 | 都能访问，无黑屏或循环重启 |

## 执行顺序

1. **只读清单**：`scripts/tv-preflight.sh`，识别在用应用；截图记录常用服务和会员状态。
2. **先只配置 Projectivy 常用分类**，不精简、不清数据。
3. 验收米家/爱奇艺/IPTV；仅在功能正常时考虑逐个处理已确认可移除的广告组件。
4. 每次只改一类，记下变更、回滚命令，变更后立即复测关键功能。
5. 一旦出现会员播放异常、米家联动失效或黑屏，停止后续改动并先回滚最近的系统变更。

**禁止的快捷方式**：直接 `pm clear` 付费视频/米家；批量删除未知 Xiaomi/GITV/Bestv/牌照包；
修改安全设置覆盖无障碍服务完整列表（会误删小爱服务）；为 IPTV 关闭路由器组播/变更运营商 VLAN。
