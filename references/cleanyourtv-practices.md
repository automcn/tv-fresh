# 借鉴 CleanYourTV：安全检查、按机型配置、精确恢复

本项目的定位是 **MIUI TV 轻量焕新**，不是复制 [CleanYourTV](https://github.com/Gathin23/cleanyourtv) 的整套新 Launcher。

| 参考能力 | tv-fresh 本次措施 | 限制 |
| --- | --- | --- |
| 变更前先探测 | `scripts/tv-preflight.sh <IP>` 列出机型、系统及疑似米家/视频包 | **只读**，不能推断会员是否有效 |
| 清理先预览 | `mitv-debloat.sh debloat <IP>` 默认列候选 | 不自动禁用 |
| 每次只停一个包 | `debloat <IP> --apply <单包>` | 只允许已登记的特定机型；候选不是通用安全名单 |
| 变更前留快照 | 记录固件、安装与已禁用包、HOME 状态；电脑本地保存 | 不采集账号密码、会员令牌 |
| 精确恢复 | `restore <IP> <快照目录>` 仅恢复本次停用的组件 | 固件升级后禁止无核对自动恢复 |
| HOME 护栏 | `sethome` 仅尝试首选桌面，保留原厂桌面和 AOSP Settings | 不自动强制接管 HOME |
| 真实遥控器回归 | 进入 HDMI、会员视频、米家、小爱与投屏 | 脚本测试不能代替真机 |
| 固件更新后检查 | 重跑只读盘点，对比当前状态 | 不自动套用旧清理名单 |

## 安全红线

1. **不 Root、不刷机、不用 `pm uninstall --user 0`**；系统清理采用 `pm disable-user --user 0`，原样恢复。
2. 不自动变更 `com.android.tv.settings`、系统输入源服务、原厂桌面、米家、小爱、电视端付费应用、DRM、账号登录、投屏及电信 IPTV。
3. 不采用其他型号的“清理全家桶”。同型号的不同固件也需核对。
4. 需要用户明确决定是否停用某个组件；拿不到授权或当前设备型号不明确时只输出清单。
5. 电视调试结束要在电视设置里关闭 ADB，尤其不要将 TCP 5555 暴露到公网。
6. 只在原设备上使用本地快照，不把家庭网络地址、设备编号或原始包快照上传 GitHub。

## MiTV-ASTP0 的特殊经验

CleanYourTV 有多个固件实测记录：
[该型号的 HDMI 与桌面记录](https://github.com/Gathin23/cleanyourtv/blob/main/examples/xiaomi-mitv-astp0/README.md)。

- 某固件的默认 HOME 仍指向 PatchWall，直接禁用会落到 FallbackHome。
- 另一个固件在换用不同第三方桌面 applicationId 后，能直接指定 HOME，原厂桌面无需禁用。
- HDMI1/2/3 的切源在一台测试机上使用小米 `EXTSRC_PLAY`，并携带整型参数；不可将该输入源编号视作其它固件的通用值。
- 上游某清理清单是以**主动舍弃米家、小爱、投屏等功能**为前提完成的。本项目要求保留这些功能，**不能直接复制该清单**。

## 真实验收

在任何修改前和修改后，至少完成一轮：
HOME 键、开机恢复、系统设置、遥控器/声音、上海电信 IPTV（直播/回看及返回）、爱奇艺/银河奇异果会员付费片、米家控制、小爱语音、手机投屏。

如果没有真实电视授权，只跑脚本语法与模拟 ADB 测试，标注为 **未真机验证**。
